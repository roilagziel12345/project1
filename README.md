# כרטיס ביקור דיגיטלי — רועי לגזיאל

אתר אישי רספונסיבי שנבנה באמצעות HTML ו־CSS בלבד. האתר כולל מצב בהיר וכהה ללא JavaScript, אזור אודות, כישורים, פרויקטים ופרטי קשר.

## מבנה הפרויקט

- `index.html` — מבנה ותוכן האתר
- `style.css` — כל העיצוב, הרספונסיביות ומצבי התצוגה
- `assets/fictional-devops-profile.png` — איור פרופיל פיקטיבי (ניתן להחליף בתמונה אחרת באותו שם)
- `links.txt` — שני הקישורים הנדרשים להגשה במודל

## פרסום ב־GitHub Pages

1. מעלים את שלושת רכיבי הפרויקט (`index.html`, `style.css` והתיקייה `assets`) ל־Repository ציבורי.
2. ב־GitHub נכנסים אל **Settings → Pages**.
3. תחת **Build and deployment** בוחרים **Deploy from a branch**.
4. בוחרים את הענף `main`, את התיקייה `/ (root)` ולוחצים **Save**.
5. לאחר הפרסום מעתיקים את קישור האתר ואת קישור ה־Repository להגשה.
